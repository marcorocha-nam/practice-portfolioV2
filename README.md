# Marco Rocha portfolio - ready for 620-V2

## Upload

1. Open https://github.com/marcorocha-nam/620-V2.
2. Choose Add file > Upload files.
3. Drag all contents of this folder into the upload area, including the _includes, _layouts, _sass, and assets folders.
4. Do not upload the ZIP itself or an enclosing folder.
5. Commit directly to main.
6. Keep Settings > Pages set to Deploy from a branch, main, / (root).
7. In Actions, wait for pages build and deployment to succeed.
8. Visit https://marcorocha-nam.github.io/620-V2/ and press Ctrl+F5.

The official Minimal theme is preserved and customized with navy and teal colors, sidebar navigation, a circular portrait, and a mobile layout.
The supplied resume is preserved. Phone number and home address are omitted.
The photo is converted from JPG to PNG without changing the decoded pixels.
The theme ZIP was downloaded from https://github.com/pages-themes/minimal/archive/refs/heads/master.zip.
